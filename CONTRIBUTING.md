# Contributing to SPARROW

Thank you for your interest in contributing to the SPARROW unofficial mobile wallet! 

## How to Contribute

1. **Fork the Repository:** Create your own fork of the repository.
2. **Create a Branch:** Create a feature or bugfix branch (`git checkout -b feature/awesome-feature`).
3. **Commit your Changes:** Make your changes and commit them with descriptive messages.
4. **Push to your Fork:** Push your branch to your fork on GitHub.
5. **Open a Pull Request:** Submit a PR against the `main` branch of this repository.

## Reporting Issues

If you find a bug or have a feature request, please open an issue in the GitHub repository. Provide as much detail as possible, including steps to reproduce bugs.

## Contact

For any questions or discussions, you can reach out to the developer, Ryan Shelby, at ryn@disr.it.
